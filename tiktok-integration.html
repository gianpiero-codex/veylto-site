TikTok integration

Seller-controlled TikTok draft uploads from Veylto Social Studio.

Veylto is desktop software for Etsy sellers. Its Social Studio lets an authorized seller prepare promotional video content, connect their own TikTok account, review the selected video and then upload that video to TikTok as a draft. Final editing and publishing remain under the seller's control in TikTok.

Products and scopes

Every requested TikTok permission has one visible purpose.

The integration requests only the products and scopes needed for account identification and seller-initiated draft upload.

01

Login Kit · user.info.basic

The seller chooses Connect TikTok and completes TikTok authorization. Veylto uses user.info.basic to identify the connected account in the interface using basic profile information such as the display name and avatar returned by TikTok.

02

Content Posting API · video.upload

After the seller manually selects and reviews a video, Veylto uses video.upload to upload that file to the authorized TikTok account as a draft. The seller then continues the editing and publishing flow inside TikTok.

03

No Direct Post

Veylto does not request video.publish for this integration and does not publish TikTok posts automatically. Uploading a draft and publishing a post are intentionally separate actions.

End-to-end flow

What the seller does in Veylto.

01

Connect TikTok

The seller starts TikTok authorization from Veylto and grants the requested permissions to their own TikTok account.

02

Confirm the account

Veylto displays the connected TikTok identity using the basic profile information authorized through user.info.basic.

03

Select and review a video

The seller chooses the local video to upload and reviews the prepared social content before any upload starts.

04

Upload as a draft

The seller explicitly starts the upload. Veylto shows progress and sends the selected file through the Content Posting API using video.upload.

05

Complete in TikTok

The uploaded content remains a TikTok draft. The seller completes any final editing and decides whether and when to publish it from TikTok.

Desktop authorization

The website page is informational, not the OAuth callback.

Veylto uses TikTok's desktop authorization flow. The OAuth response returns to the registered local loopback redirect used by the desktop application. This public page documents the integration for users and reviewers; it is not used as the desktop OAuth redirect endpoint.

✓

Authorized account only
Veylto acts only after the TikTok user completes authorization for their own account.

✓

Manual upload action
The seller selects the video and explicitly starts each upload.

✓

No mass posting or scraping
The integration is not designed to scrape TikTok or automatically mass-post content.

✓

Publishing remains in TikTok
Draft upload does not silently publish content to the seller's profile.

Sandbox and review

The review demo uses TikTok Sandbox to show the real Veylto flow.

For TikTok review, a permitted Sandbox target user can be used to demonstrate the complete flow: opening Veylto, connecting TikTok, showing the connected profile identity, selecting a video, starting the upload and confirming that the content reaches TikTok as a draft. LuminareGallery may be used as the test seller account in that demonstration; the TikTok integration itself belongs to the Veylto product.
