# Veylto Site

Static public website for Veylto.

## Contents

- Product landing page
- Privacy Policy
- Terms of Service
- Etsy trademark disclaimer
- GitHub Pages custom-domain file for `veyltoapp.com`

## Deployment

Publish from the `main` branch root with GitHub Pages. Configure Namecheap DNS only after the repository and Pages site are active.

## Important before public release

- Configure `support@veyltoapp.com` before relying on support links.
- Review the privacy policy against the final production architecture.
- Review the terms with qualified legal counsel before commercial launch.
- Do not store API credentials, OAuth tokens, private configuration, customer data or runtime logs in this repository.
