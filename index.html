Product principles

Automation should not hide consequences.

Review before write

Changes that affect Etsy remain visible, confirmed and attributable.

Clear data boundaries

Security and platform respect

Designed for authorized seller access.

Veylto uses Etsy OAuth for permitted shop access. It does not scrape Etsy, request seller API credentials, bypass Etsy checkout or claim endorsement by Etsy.
