Product principles

Automation should not hide consequences.

Review before write

Changes that affect Etsy are designed to remain visible, confirmed and attributable.

No silent provider switching

The selected provider and model should be the ones actually used for the requested workflow.

Clear data boundaries

Local data, AI drafts and Etsy-applied values should remain distinguishable in the interface.

Security and platform respect

Designed for authorized seller access.

Veylto uses Etsy OAuth for permitted shop access. It does not scrape Etsy, ask sellers to share API credentials, bypass Etsy checkout, or claim endorsement by Etsy.
